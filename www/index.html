Grenadine

Pomegranate, with the JVM pressed out.

Grenadine @VERSION@ is a portable Maven dependency installer compiled with Gloat. It resolves the Maven dependencies in a local or remote deps.edn source and installs them into your local Maven repository without Java.

Use it

grenadine deps.edn
grenadine --repository=my-m2 deps.edn
grenadine --quiet deps.edn
grenadine --help
grenadine --version

HTTP and HTTPS URLs are accepted directly, including GitHub blob links:

grenadine --repository=my-m2 https://github.com/yaml/yamlscript/blob/main/core/deps.edn

Grenadine lists each newly installed dependency immediately, then prints installed, already-present, and total counts. Quiet mode suppresses this non-error output.

Run without installing

Bash or Zsh:

$(source <(curl -s clojurestar.github.io/grenadine/get)) deps.edn

PowerShell:

& ([scriptblock]::Create((Invoke-RestMethod https://clojurestar.github.io/grenadine/get.ps1))) deps.edn

The launcher selects and verifies the current release in a temporary cache. It does not modify PATH.

Platforms

Linux amd64, arm64, and armv6; macOS amd64 and arm64; Windows amd64 and arm64; and FreeBSD, OpenBSD, and NetBSD on amd64 and arm64.
